Подключить YouTube

Войдите через Google, чтобы отвечать прямо из карточек после завершения выгрузки. Для сбора и экспорта вход не нужен.

Google запрашивает разрешение на управление данными YouTube. Расширение использует его для определения вашего канала и отправки только написанных вами ответов.

Проблемы со входом?

В Google Cloud должен быть клиент типа Chrome Extension, привязанный к этому ID расширения. Ваш аккаунт должен быть добавлен в тестовые пользователи.
