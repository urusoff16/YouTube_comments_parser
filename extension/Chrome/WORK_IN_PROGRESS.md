# Состояние версии 1.3.0 — библиотека видео и черновики

Обновлено: 2026-10-16.

- IndexedDB обновлён до схемы 2. Комментарии, счётчики, черновики и история отправки разделены по video ID; черновики дополнительно разделены по адресу комментария и channel ID.
- Прежняя таблица версии 1.2 сохраняется без изменений. Интерфейс предлагает явно привязать прежний набор к введённой ссылке; автоматического угадывания нет. Исходная таблица остаётся резервной копией.
- Повторный сбор объединяет ID, а не очищает библиотеку. Перезагрузка открывает сохранённые данные без сетевого сбора; новый запуск делается кнопкой.
- Добавлены выбор видео, восстановление, автосохранение черновика и сохранение неопределённой отправки между перезагрузками. Подтверждённый ответ, история и удаление его черновика записываются одной транзакцией.
- Операции сбора, отправки, импорта и удаления защищены Web Locks по видео; удаление затрагивает только выбранный набор.
- Проверены 37 модульных тестов, синтаксис и 24 браузерных сценария с подставными Identity/API и настоящим IndexedDB Chrome. Проверены JSON/TXT с опубликованным тестовым ответом, миграция тестовой базы схемы 1 и вход в библиотеку из popup без сетевого сбора.
- Вход и реальную публикацию из версии 1.2.0 пользователь подтвердил самостоятельно после добавления email в Google test users. Это не самостоятельная публикация агента.

Остаётся ручная проверка обновления именно пользовательской установки: закрыть старые страницы расширения, перезагрузить его в прежней папке и проверить восстановление своих данных/черновиков. Новые реальные ответы агент не публиковал. Публичный OAuth, постоянный ID, другие аккаунты/браузеры, MCP и мониторинг остаются следующими этапами. Новую версию AGENTS.md не изменяли; она предназначена для будущей подготовки ответов.

## История версии 1.2.0 — Google OAuth и официальный API ответов

Обновлено: 2026-10-16.

- Предоставленный публичный Client ID подключён к manifest; исходный JSON не копируется в релиз.
- Добавлены вход/восстановление без интерактивного окна, отображение канала, отключение и помощь с ID расширения.
- Интерфейс отправляет ответы через `comments.insert` с повторной проверкой канала и корневым parent ID. Внутренний способ отправки не используется интерфейсом.
- Один ответ сохраняется атомарно в IndexedDB вместе со счётчиком родителя. При сетевом обрыве отправка не повторяется; локальная ошибка после успешного API-ответа не разрешает новый POST.
- Добавлены RU/EN, стили обеих тем, политика конфиденциальности и инструкция OAuth.
- 37 модульных тестов прошли; синтаксическая проверка прошла.
- Браузерный тест с подставными Identity/API прошёл: отправка, IndexedDB, двойной submit, выход, неизвестный результат, отказ локального хранилища, отмена входа, RU/EN, обе темы и мобильная ширина.

Позднее пользователь подтвердил успешный Google-вход и один ответ в правильной ветке YouTube. Исходный JSON не содержит Item ID; работа подтверждена для текущей установки, а не для произвольной распакованной папки.

Обновлять существующую установку в той же папке. Новая распакованная папка может изменить ID и нарушить OAuth-привязку. Перед публичным выпуском зафиксировать постоянный ID и пройти необходимые проверки OAuth. MCP и мониторинг ещё не реализованы; ТЗ находится в `../../OAUTH_MCP_SPEC.md`.

## История версии 1.1.0 — исправление запуска и ответов

Обновлено: 2026-09-13.

## Уже реализовано

- цветные уровни вложенности ответов с вычислением адресата по `@упоминанию`;
- подпись «ответил кому» рядом с автором;
- кнопка ответа в карточке комментария;
- встроенный редактор ответа, счётчик символов, отмена и явная отправка;
- одиночный POST-запрос без автоматических повторов, чтобы не создавать дубликаты;
- русская и английская локализация новых элементов и ошибок;
- тестовая HTML-сцена для будущей визуальной проверки.
- автоматическое подключение content script к уже открытой вкладке после обновления расширения;
- переиспользование подходящей вкладки YouTube вместо открытия лишней;
- разбор актуальной связи `toolbarSurfaceKey` → `engagementToolbarSurfaceEntityPayload` → reply-команда.

## Уже проверено

- `npm.cmd test`: 21/21 тест прошёл;
- `npm.cmd run check`: синтаксис всех JavaScript-модулей корректен.
- публичная выгрузка первых 20 комментариев тестового видео через текущий сетевой парсер прошла;
- тёмная тема дерева и редактора визуально проверена в Chrome Headless.

## Что проверить следующим запуском

1. Установить или перезагрузить сборку 1.1.0 в пользовательском Chrome.
2. Проверить полный сбор через авторизованную вкладку YouTube.
3. Проверить появление reply-команд в авторизованном ответе YouTube.
4. Только после отдельного подтверждения пользователя отправить один тестовый ответ.
5. Если живой формат reply-эндпоинта отличается, адаптировать тело запроса по фактической ошибке.

## Важные ограничения

- отправка ответа через внутренний интерфейс YouTube пока не проверена на живом аккаунте;
- светлая тема и мобильная ширина нового дерева ещё не осмотрены;
- внешний комментарий в ходе разработки не публиковался;
- каталог не является Git-репозиторием, поэтому Git-коммит создать невозможно без отдельной инициализации.
