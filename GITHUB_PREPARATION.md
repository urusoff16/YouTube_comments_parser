# Подготовка к публикации на GitHub

Исходный код и инструкции находятся в репозитории. Файлы с API-ключами, OAuth JSON, выгрузками комментариев, локальным виртуальным окружением, готовыми архивами и локальным рабочим журналом `WORK_IN_PROGRESS.md` исключены из текущего состава через `.gitignore` и остаются на устройстве.

В `extension/Chrome/manifest.json` указан OAuth Client ID разработчика. Client ID является публичным идентификатором, но его авторизация привязана к конкретному ID расширения и настройкам Google Cloud. Установка из другой папки или другим пользователем может потребовать собственного OAuth-клиента и настройки разрешений. Функция входа проверялась владельцем на его текущей установке; публичная OAuth-верификация и стабильный ID для распространения остаются открытыми вопросами.

Для создания ZIP локально используйте `npm.cmd run build:release` из `extension/Chrome`. Сборки в Git не включены. Перед публичной публикацией проверьте README, политику конфиденциальности, содержимое релиза, права на изображения и выберите подходящую лицензию. Отсутствие файла лицензии не предоставляет другим пользователям стандартного разрешения на использование и изменение кода.

Репозиторий создан локально. Для публикации необходимо выбрать GitHub-репозиторий и настроить удалённый адрес; само создание коммита не публикует проект.
